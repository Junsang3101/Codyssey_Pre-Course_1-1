# Codyssey_Pre-Course-1-1
코디세이 입학 연수1-1) "내 컴퓨터에 개발자용 '작업실' 꾸미기

프로젝트 개요
    터미널, Docker, Git를 이용하여 간단한 웹 서버를 Dockerfile로 컨테이너화하고 포트 매핑으로 접속을 확인하며, 바인드 마운트/볼륨으로 "변경 반영"과 데이터 영속성"을 직접 검증.
    실행 결과(로그/접속/데이터 유지)로 핵심 흐름을 확인하며,
    이미지와 컨테이너 분리, 격리된 실행 환경 , 포트/스토리지 연결 방식이라는 구조적 원칙을 적용해 왜 이런 설계가 필요한지 정리하여 같은 서비스를 여러 번 실행해도 재현되는 환경을 만드는 사고방식을 경험.

실행 환경
    OS: Ubuntu 26.04.1 LTS
    Shell: bash
    Docker: Client:29.9.2, Server:29.9.2 
    Git: 2.56.0.windows.4

    [x] hello-world 실행
    [x] Dockerfile 실행
    [x] 바인드 마운트 반영
    [x] 볼륨 영속성
    [x] Git 설정 + VSCode GitHub 연동
